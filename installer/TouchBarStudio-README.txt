Touch Bar Studio

Конструктор для Touch Bar: кнопки приложений, медиа-клавиши, горячие клавиши, часы, страницы.

1. Сначала установите драйвер (Install.cmd в корне архива) и перезагрузитесь.
2. Запустите TouchBarStudio.exe. Если пишет, что устройство не открывается, выберите
   Settings -> Restart as administrator.
3. Add item добавляет кнопку. Справа настраиваются подпись, действие, цвета и иконка.
4. Верхняя полоса в окне - живой предпросмотр. По ней можно кликать мышью, чтобы проверить кнопки,
   даже если касания на Touch Bar ещё не работают.
5. Окно можно закрыть: программа остаётся в трее и продолжает управлять Touch Bar.
   Settings -> Start with Windows включает автозапуск.

Настройки хранятся в %APPDATA%\TouchBarStudio\config.json.

Важно: программа не проверялась на реальном железе. Касания читаются из HID-устройства
05AC:8302 по схеме из проекта imbushuo/DFRContentHost; если касания не срабатывают,
кнопки всё равно можно проверять мышью в предпросмотре.
